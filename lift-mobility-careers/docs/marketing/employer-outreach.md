# Employer outreach process (compliant, controlled)

**Goal:** relationships with 50–100 UK direct employers in the sector. **Offer:** one free, authorised 30-day Standard listing; paid packages afterwards. **No bulk email – ever.**

## 1. Build the list (Outreach CRM)
1. Import `data/target-employers.csv` (CRM → Import). Every row is an **unverified lead**.
2. For each company: look it up on **Companies House** → set *entity type* (Ltd/PLC/LLP = corporate; sole trader/partnership = individual). Record the company number.
3. Find the official careers page → paste into *Careers page URL* (adds it to discovery monitoring). Read the site's terms; tick "terms reviewed" in Discovery only if automated checking isn't prohibited.
4. Contact: use a **published role-based address** (careers@, recruitment@, hr@) or a named recruiting manager whose business email is published. Note where you found it.

## 2. Decide the channel
| Entity | Email allowed? | Better first step |
|---|---|---|
| Ltd / PLC / LLP / public body | Yes (B2B) – the CRM adds ID, address, unsubscribe | Email |
| Sole trader / partnership / unknown | **Blocked** unless consent recorded | Phone call or LinkedIn message; ask permission to email |

## 3. Send – one at a time
CRM → prospect → **Compose email** → choose template (*Free listing offer* or, for a discovered vacancy, *May we feature your vacancy?*) → read the preview → tick the confirmation → Send. Status, last-contacted and a follow-up date (+10 days) are recorded automatically. Max 10/day by default.

## 4. Follow up once
When the follow-up is due (dashboard tile), send the *Follow-up* template **once**. After two contacts without a reply the CRM blocks further emails. Mark as *Not interested* if they decline; unsubscribes are suppressed automatically and permanently.

## 5. When they say yes
1. Ask them to register (link in email) – or create the account on their behalf only with their agreement.
2. CRM → prospect (now linked to the account) → **Grant free 30-day listing** (one credit, valid 90 days).
3. They post the vacancy and choose *Use 1 standard credit*. Or, for a discovered vacancy they've authorised in writing: Discovery → *Employer approved → draft*, write an **original** summary, send it to them to check, then publish. Save their permission email.
4. Set permission status (vacancies / vacancies + logo) in the CRM.

## 6. Convert
The system then handles expiry reminders, "did you fill it?" and the repeat-advertising nudge (which respects their marketing opt-out). Status flips to *Paying customer* automatically after the first payment.

## Weekly 30-minute routine
Monday report → approve pending adverts → review new discovered vacancies → send 5–10 outreach emails → clear follow-ups → copy social drafts.
